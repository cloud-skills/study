# 26년 5월 19일 Day2 세션

## 학습 질의응답
**외우는게 힘들다** : 기본적으로 모든 기능을 외워서 학습하면 안되며, 기능을 특징과 비슷한 서비스끼리 어떤 차이를 가지고 있는지 학습.
  - 좋은 예 : IAM Role에 EC2가 assume 할 수 있으며, IAM Key 방식에 비해서 keyless로 보안이 향상되는 장점 존재. EFS의 경우 EBS와 달리 NFS 프로토콜로 마운트되며 네트워크를 타기 때문에 Security Group이 존재.
  - 안좋은 예 : 작년 2과제 EC2 문제 풀때 생성 버튼 누르고 IAM 란에 Role 입력해서 생성하고, EFS 하나 만들어서 설정하면 10점 임.

**직종이 얼마 안돼어 과제가 별로 없다** : 먼저 서비스 별 이해와 학습이 필요하고, 기술은 모른채로 과제만 풀어보는 학습 방식은 좋지 않음. 또한 지방과 전국 국제대회 과제가 5년치가 쌓여 있으며, aws-samples와 같은 Github에 수천개의 샘플이 이미 있어 해당 아키텍쳐들을 구축해보면서 학습하면 보는것을 권장함.
  https://github.com/aws-samples
  - 좋은 예 : EC2와 CI/CD 기능을 조합하여 실제로 아키텍쳐를 만들어 본다. aws-samples에서 학습한 주제와 관련된 샘플 아키텍쳐를 보고 실제 구축해본다.
  - 안좋은 예 : AWS 기술 학습은 하지 않고 단순 과거 과제만 풀어보며 얼마나 빨리 푸는지만 측정함. 과제는 풀어 보지만 내가 설정하는 Policy와 Configuration이 어떤것을 의미 하는지 모름.

**코드 개발이 힘들다** : Claude-code나 codex를 활용해 원하는 앱 하나 개발 해보는것을 추천함. 또한 과제에 REST API 구현이 있기 때문에 람다에 배포할 수 있는 Python 정도는 간단히 학습 하는걸 권장.

**트러블 슈팅이 힘들다** : 트러블 슈팅시 먼저 로그를 확인하고, 문제되는 시스템을 계층 별로 나눠 차례로 이상 없는지 확인해 나가는 전략을 익혀야 함.

**기능이 너무 많다** : 처음에는 자주 사용되는 서비스들 위주로 학습을 해도 충분함. 자주 쓰는 서비스는 AWS 인기도로 검색하면 나오며, 과제에서 자주 등장하는 서비스도 해당함.

**과제 풀다가 리소스가 한번에 삭제됨** : IaC 도구를 통해 작업하다가 다 삭제 되는 경우에는 먼저 삭제에 유의하고, 리소스를 적당한 폴더화 등을 통해 Apply 단위를 나눠 작업 실수에 대비 권장.
